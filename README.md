# Raviraja Quotations

Quotation, proforma and tax invoice app for Raviraja Industries.

**Open the app:** https://vijaykumarreddy101234-gif.github.io/quotation-of-window/

- Android (Chrome): open the link, tap ⋮ → **Install app**
- iPhone (Safari): open the link, tap Share → **Add to Home Screen**

Data is stored on each phone. Use Settings → Backup / Restore to move it between phones.
First login: `admin` / `Admin@1234` — change the password in Settings → Users & roles.
